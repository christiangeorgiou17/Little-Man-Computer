# MEMORY

This is a global list that initially contains a string of three zeros for each of the 100 available memory locations.

    "000", "000", "000", "000", "000", "000", "000", "000", "000", "000",
    "000", "000", "000", "000", "000", "000", "000", "000", "000", "000"

* **`MEMORY.length`** is equal to `100`.
* **`MEMORY[x]`** is equal to `"000"` initially. After assembly or execution, its value can be any string from `"000"` to `"999"`, always with a length of three characters. Valid integer indices satisfy `0 <= x < 100`.
